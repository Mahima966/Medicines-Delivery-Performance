# Medicines-Delivery-Performance
<hr>
<div align="center">

<h2>📦 Project Summary:</h2>

<p><strong><p><strong>Analyzed an online medicine delivery dataset with city-wise order details</strong>, focusing on complete order lifecycle, delivery partner performance, and turnaround times (TAT).</p></p>

</div>
<hr>

<h3>📂 Key Tables:</h3>
<ul>
  <li>Order Details</li>
  <li>Store Info</li>
  <li>Customer & Location</li>
  <li>Delivery Partner</li>
  <li>TAT Logs</li>
</ul>

<hr>

<h3>⚙️ Process</h3>

<ol>
  <li>🧩 <strong>Data Integration</strong><br>
      Merged multiple source tables to create a flat file representing the full order lifecycle.
  </li><br>

  <li>🧼 <strong>Data Cleaning & Transformation</strong><br>
      Cleaned nulls, fixed formats, and standardized fields.
  </li><br>

  <li>🐍 <strong>Feature Engineering using Python</strong><br>
      Created calculated columns (stage-wise TAT, delays, flags) using Pandas & NumPy.
  </li><br>

  <li>📊 <strong>Exploratory Data Analysis (EDA)</strong><br>
      Identified patterns and bottlenecks through visual and statistical analysis.
  </li><br>

  <li>📈 <strong>Dashboard Creation</strong><br>
      Built in Power BI showing:<br>
      - City-wise volumes<br>
      - Stage-wise TAT & delays<br>
      - Store & partner performance
  </li>
</ol>
